# 03. Интерфейс: окна, вкладки, таблицы, миникарта, настройки

## CreateFrame и шаблоны

```lua
local f = CreateFrame("Frame", "MyAddonFrame", UIParent, "BackdropTemplate")
f:SetSize(780, 540)
f:SetPoint("CENTER")
f:SetFrameStrata("DIALOG")
f:SetFrameLevel(20)
```

* Тип: `Frame`, `Button`, `CheckButton`, `EditBox`, `ScrollFrame`, `Slider`,
  `StatusBar`, `GameTooltip`, `PlayerModel`/`DressUpModel`, `SimpleHTML`.
* Имя (второй аргумент) — глобал; для одноразовых элементов можно `nil`.
* `UIParent` — «экран», но не единственный родитель: миникарта, `GameTooltip`,
  `UIParent`-слои, `WorldFrame` (3D-мир).
* Шаблон даёт кнопкам/чекбоксам фон, шрифт и поведение:
  `UIPanelButtonTemplate`, `UICheckButtonTemplate`, `UIPanelCloseButton`,
  `InsetFrameTemplate`, `UIPanelScrollFrameTemplate`, `UIDropDownMenuTemplate`.
  **`SetBackdrop` работает только с шаблоном `BackdropTemplate`** — иначе
  `attempt to call a nil value (SetBackdrop)`. Это одна из самых частых ошибок.

Страты по возрастанию: `BACKGROUND`, `LOW`, `MEDIUM`, `HIGH`, `DIALOG`, `FULLSCREEN`,
`FULLSCREEN_DIALOG`, `TOOLTIP`. Внутри страты — `SetFrameLevel`.

**Окно, открытое поверх главного.** Главное окно аддона при клике поднимается наверх
своего слоя. Поэтому дочерние окна (примерочная, ссылка, лог) делают отдельными фреймами:

```lua
local sub = CreateFrame("Frame", "MyAddonSub", UIParent, "BackdropTemplate")
sub:SetFrameStrata("FULLSCREEN_DIALOG")
sub:SetFrameLevel(100)
local function ShowSub()
    sub:Show()
    if sub.Raise then sub:Raise() end
    sub:SetFrameLevel(110)
end
```

## Текст

```lua
local fs = f:CreateFontString(nil, "OVERLAY", "GameFontNormal")
fs:SetPoint("TOPLEFT", 12, -12)
fs:SetText("Список")
fs:SetJustifyH("LEFT")
fs:SetWidth(300)
```

* Шрифты: `GameFontNormal`, `GameFontHighlight`, `GameFontDisable`, `GameFontNormalSmall`,
  `GameFontNormalLarge`, `ChatFontNormal`. Свои размеры — `GameFontNormal:GetFont()` и
  `CreateFont`/`SetFont`.
* Высота перенесённого текста: `fs:GetStringHeight()` (иногда `nil` — тогда считать
  `ceil(длина/ширина)` по символам, как в тестах).
* Обрезка длинного: `SetWordWrap(false)` + `SetMaxLines(1)`, а «...» добавить вручную
  (`text:sub(1, n) .. "..."`). В 12.x есть `Ellipsize`/`SetMaxLines`, но под рукой не всегда.
* Цвет — **только числами**:

```lua
fs:SetTextColor(1, 0.82, 0)          -- ок
fs:SetTextColor(colorTable)          -- ошибка "bad argument #1 to 'SetTextColor'"
local c = ITEM_QUALITY_COLORS[Enum.ItemQuality.Legendary]; fs:SetTextColor(c.r, c.g, c.b)
local cr = RAID_CLASS_COLORS[select(2, UnitClass("player"))]
```

## Кнопки, чекбоксы, слайдеры

```lua
local b = CreateFrame("Button", nil, f, "UIPanelButtonTemplate")
b:SetSize(110, 22); b:SetText("Открыть"); b:SetPoint("TOPLEFT", 12, -40)
b:SetScript("OnClick", function() ns.UI.Toggle() end)
b:SetScript("OnEnter", function(self)
    GameTooltip:SetOwner(self, "ANCHOR_RIGHT"); GameTooltip:SetText("Подсказка"); GameTooltip:Show()
end)
b:SetScript("OnLeave", function() GameTooltip:Hide() end)

local cb = CreateFrame("CheckButton", nil, f, "UICheckButtonTemplate")
cb:SetSize(24, 24); cb:SetPoint("TOPLEFT", 12, -70)
cb.label = cb:CreateFontString(nil, "OVERLAY", "GameFontNormal")
```

В 12.x у чекбоксов есть `SetChecked`/`GetChecked` (в старых шаблонах — `SetChecked` был
только у некоторых типов). Безопасно: `pcall(cb.SetChecked, cb, v)`, своё состояние
хранить в БД и перерисовывать `Update()`.

## Вкладки: самый простой работающий паттерн

Не надо `UIPanelTemplates` из Blizzard: вкладки — это кнопки + пул страниц.

```lua
ns.UI.pages = {}
local function NewPage()
    local p = CreateFrame("Frame", nil, f)
    p:SetAllPoints(f.content)
    p:Hide()
    return p
end

function ns.UI.ShowTab(key)
    for k, p in pairs(ns.UI.pages) do p:SetShown(k == key) end
    ns.db.ui.tab = key
    ns.UI.Refresh()
end
```

Кнопка вкладки: `UIPanelButtonTemplate`, активную выделять `SetButtonState`/своим цветом.
Страницы фиксированного размера (в Drop Ledger — 752×444) и общий каркас вокруг них:
смена компоновки не требует переписывать страницы.

## Списки и таблицы

Правильный список — **пул строк**, а не «создать по фрейму на запись»:

```lua
local ROW_H = 20
local rows = {}
local function Row(i)
    if rows[i] then return rows[i] end
    local r = CreateFrame("Button", nil, f.scrollChild)
    r:SetHeight(ROW_H)
    r:SetPoint("TOPLEFT", 0, -(i - 1) * ROW_H)
    r:SetPoint("RIGHT", f.scrollChild, "RIGHT", 0, 0)
    r.icon = r:CreateTexture(nil, "ARTWORK"); r.icon:SetSize(18, 18)
    r.text = r:CreateFontString(nil, "OVERLAY", "GameFontHighlightSmall")
    r:SetScript("OnClick", function() ns.UI.Select(r.dataID) end)
    rows[i] = r
    return r
end
```

Обновлять только видимые строки, данные — из кэша (`Stats.lua`, `ns.ItemMeta`), а не
`C_Item.GetItemInfo` на каждую перерисовку. Пришедшее `GET_ITEM_INFO_RECEIVED` обновляет
**одну** строку (`UI.RefreshItem(id)`), а не весь список.

### Своя прокрутка

Штатный `UIPanelScrollFrameTemplate` листает страницей и «прыгает». Если нужен пиксельный
скролл (как в Drop Ledger):

* `ScrollFrame` + child-фрейм высотой `rows * rowH`, у родителя `SetClipsChildren(true)`
  (или `SetClipsChildren` на самом scrollframe в актуальных сборках);
* `EnableMouseWheel` + `OnMouseWheel` двигает `child:SetPoint("TOPLEFT", 0, offset)`;
* стрелки двигают на строку, клик по дорожке — на экран, ползунок — `GetCursorPosition`
  в координатах фрейма;
* колесо/перетаскивание не должны ломать выбор строки.

### Высота строки по тексту

```lua
local h = r.text:GetStringHeight() or ROW_H
if h > ROW_H then r:SetHeight(h + 4) else r:SetHeight(ROW_H) end
```

Пересчитывать позиции строк после изменения высоты (иначе наезжают друг на друга) —
проще держать массив накопленных Y и перекладывать.

## Тултипы

```lua
GameTooltip:SetOwner(self, "ANCHOR_RIGHT")
if self.itemID then
    GameTooltip:SetItemByID(self.itemID)
else
    GameTooltip:SetText("Заголовок")
end
GameTooltip:AddLine("Строка", 1, 1, 1, true)   -- true = перенос
GameTooltip:Show()
```

`SetItemByID` требует загруженных данных; если предмет неизвестен — `SetText` с именем
из своего кэша, иначе пустой тултип.

## Окно: перетаскивание, позиция, Esc, масштаб

```lua
f:SetMovable(true)
f:EnableMouse(true)
f:RegisterForDrag("LeftButton")
f:SetScript("OnDragStart", f.StartMoving)
f:SetScript("OnDragStop", function(self)
    self:StopMovingOrSizing()
    local point, _, relPoint, x, y = self:GetPoint()
    ns.db.ui.pos = { point = point, relPoint = relPoint, x = x, y = y }
end)
f:SetClampedToScreen(true)

tinsert(UISpecialFrames, "MyAddonFrame")   -- Esc закрывает
f:SetScale(ns.db.ui.scale or 1)            -- масштаб сохранять в БД
```

Не забыть `IsShown()`-проверку в тумблере: `/ma` открывает/закрывает, а не «всегда
открыть».

## Кнопка у миникарты

Классический паттерн, работает во всех клиентах:

```lua
local b = CreateFrame("Button", "MyAddonMinimapButton", Minimap)
b:SetSize(32, 32)
b:SetFrameStrata("MEDIUM")
b:SetFrameLevel(Minimap:GetFrameLevel() + 10)
b:RegisterForDrag("LeftButton")

b.border = b:CreateTexture(nil, "BACKGROUND")
b.border:SetSize(54, 54); b.border:SetPoint("CENTER")
b.border:SetTexture("Interface\\Minimap\\MiniMap-TrackingBorder")

b.icon = b:CreateTexture(nil, "ARTWORK")
b.icon:SetSize(20, 20); b.icon:SetPoint("CENTER", 0, 1)
b.icon:SetTexture("Interface\\Icons\\INV_Misc_Coin_01")
b.icon:SetTexCoord(0.08, 0.92, 0.08, 0.92)

local angle = ns.db.ui.minimapAngle or 220
local function Place(a)
    local w = (Minimap.GetWidth and Minimap:GetWidth()) or 140
    if not w or w < 40 then w = 140 end
    local radius = w / 2 + 5
    b:ClearAllPoints()
    b:SetPoint("CENTER", Minimap, "CENTER",
        radius * math.cos(math.rad(a)), radius * math.sin(math.rad(a)))
end
Place(angle)

b:SetScript("OnClick", function(_, button)
    if button == "RightButton" then ns.UI.MinimapMenu(b) else ns.UI.Toggle() end
end)
b:SetScript("OnDragStart", function(self)
    self:SetScript("OnUpdate", function()
        local mx, my = Minimap:GetCenter()
        local scale = Minimap:GetEffectiveScale() or 1
        local cx, cy = GetCursorPosition(); cx, cy = cx / scale, cy / scale
        local a = math.deg(math.atan2(cy - my, cx - mx))
        angle = a; ns.db.ui.minimapAngle = a; Place(a)
    end)
end)
b:SetScript("OnDragStop", function(self) self:SetScript("OnUpdate", nil) end)
```

`math.atan2` в Lua 5.1 нет — `math.atan2 or function(y,x) return math.atan(y,x) end`.

Меню по правому клику:

## Страница в «Настройки → Аддоны»

```lua
function ns.UI.RegisterOptions()
    if ns.UI.optCategory then return end
    if not (Settings and Settings.RegisterCanvasLayoutCategory and Settings.RegisterAddOnCategory) then
        return                     -- старый клиент: страницы нет, окно всё равно работает
    end
    local panel = CreateFrame("Frame")
    panel:SetSize(560, 420)
    -- ... свои чекбоксы ...
    local ok, category = pcall(Settings.RegisterCanvasLayoutCategory, panel, "MyAddon")
    if ok and category then
        pcall(Settings.RegisterAddOnCategory, category)
        ns.UI.optCategory = category
    end
end
```

Регистрировать на `PLAYER_LOGIN`, а не в момент загрузки файла. Всегда через `pcall`:
в клиентах без новых `Settings` вызов падает и роняет аддон.

## Плашка уведомлений (Popup)

Свойства, которые нужны пользователю:

* отдельный фрейм на `FULLSCREEN_DIALOG`, не мешает окну;
* перетаскивание + сохранение позиции в БД (в Drop Ledger — `db.ui.popupPoint`);
* `SetClampedToScreen(true)`, показ 8 секунд, последние 0.6 с — фейд через
  `UIFrameFadeOut`; правый клик скрывает сразу;
* иконка предмета отложенная: пока `C_Item.GetItemInfo` пуст — знак вопроса,
  затем `GET_ITEM_INFO_RECEIVED` подменяет текстуру;
* текст берётся из той же функции, что и сообщение в чат (`ns.DropMessage`), чтобы каналы
  не расходились.

## Дизайн: палитры и компоновки

Проверенная схема Drop Ledger: `Theme.lua` описывает
`palette = { bg, panel, border, accent, text, dim, edit, scroll, btn, btnHover }` и
`layouts = { классика, рельс, подвал, корешок, книга, парение, плотный, плитки, терминал }`.
Компоновка — это геометрия (отступ, высота шапки, ширина рельса, положение вкладок,
`rowH`), палитра — цвета. Рабочая область страниц фиксированная, каркас двигается вокруг.
Цвет класса собирается из `RAID_CLASS_COLORS`, а не из 13 наборов констант.

Практика: любой «скин» должен проходить проверку «серый текст и цветные цифры читаемы»
на всех палитрах, включая светлую.

## Мелочи, которые замечает пользователь

* В шрифте клиента **нет** символов `·`, `−`, `✓`, `→`, `…` — вместо них пустые квадраты.
  Использовать `•`, `-`, `>`, `...` (проверено на ruRU-клиенте 12.x).
* Кнопка с текстом шире самой кнопки обрезается; считать ширину по длине строки.
* Длинное имя предмета без `SetWordWrap(false)` ломает строку и наезжает на соседнюю.
* Смена языка требует пересобрать окно (тексты в `FontString` уже записаны).
* Esc: фрейм должен быть в `UISpecialFrames` (и вписаться туда без дублей).
* Не держать `OnUpdate` на скрытых фреймах: обработчик живёт, пока фрейм существует.
