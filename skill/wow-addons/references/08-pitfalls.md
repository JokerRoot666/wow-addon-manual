# 08. Каталог грабель: симптом → причина → лечение

Всё ниже — реальные падения и баги, пойманные при разработке аддона на 12.1.x.

## Клиент 12.x: API уехал

**`attempt to call a nil value (GetItemInfo)`**
Глобал `GetItemInfo` удалён. → `C_Item.GetItemInfo(id)` (таблица) + `C_Item.GetItemInfoInstant`
для мгновенных полей; `C_Item.RequestLoadItemDataByID` + `GET_ITEM_INFO_RECEIVED` для
отложенной загрузки. Обёртка с фолбэком — в `02-api.md`.

**`attempt to call a nil value (GetSpellInfo)`**
→ `C_Spell.GetSpellInfo(id)` (таблица) / `C_Spell.GetSpellName(id)`.

**`attempt to call a nil value (GetContainerItemInfo)`**
→ `C_Container.GetContainerItemInfo/GetContainerItemID/GetContainerNumSlots`.

**Клиент падает с `ACCESS_VIOLATION` при показе модели**
`PlayerModel:SetUnit("target")` на NPC. В API вызов помечен
`RequiresDeclassifiedUnitIdentity` — у существ личность секретная, и клиент валится.
→ для игроков `SetUnit`, для существ `SetCreature(C_CreatureInfo.GetCreatureID(guid))`.

**«клиент не отдаёт модель этого юнита» на любом юните**
`CanSetUnit` в 12.x возвращает **secret value**; сравнение с `true` не даёт `true`.
→ не спрашивать `CanSetUnit`; вызывать `SetUnit`/`SetCreature` и считать переключением
только если клиент реально согласился (нет ошибки / модель показывает юнита).

**`C_CreatureInfo.GetRaceInfo` даёт `nil`/«раса 7»**
В 12.x поле переименовано `name` → `raceName`. → читать оба: `info.raceName or info.name`.

**Скан трансмога «ничего не находит»**
`C_TransmogCollection.GetCategoryAppearances` (и `GetCategoryList`) в 12.x отдают пусто.
→ перебирать **свою** базу предметов и спрашивать `PlayerHasTransmog(itemID)`; для наборов —
`C_Transmog.GetAllSetAppearancesByID` (а не прежний путь через внешности набора).

**`ADDON_ACTION_FORBIDDEN` и аддон перестал работать**
`RegisterEvent("COMBAT_LOG_EVENT_UNFILTERED")` (или событие, живущее только в боевом
логе) — защищённый вызов. `pcall` не спасает: нарушение всё равно засчитывается.
→ не регистрировать; проверять `C_Secrets`/`C_CombatLog`/`GetBuildInfo()` до подписки;
альтернативный счёт без лога (цель + здоровье) — по умолчанию выключен.

**Регистрация событий в `ADDON_LOADED` иногда «травит» аддон**
→ отложить на кадр: `C_Timer.After(0, start)`. Проверено на Drop Ledger: без этого часть
защищённых вызовов помечается taint.

**Событие, которого нет в клиенте**
`RegisterEvent` на несуществующее имя молча ничего не даёт или ругается.
→ `C_EventUtils.IsEventValid(event)` перед подпиской (`02-api.md`).

## Секретные значения

**`attempt to compare number with secret value` / «a secret number value, while execution
tainted by ...»** — любое значение из клиента может быть secret: здоровье чужих юнитов,
некоторая информация о NPC, часть данных в подземельях. → `issecretvalue()` перед любым
сравнением/арифметикой; для аддона secret = «данных нет» (`ns.Open`/`ns.Probe`).

**В подземельях счётчик убийств молчит** — здоровье врагов секретное, «дошло до нуля» не
сравнить. → честно писать в интерфейсе «оценочно/недоступно», не пытаться обойти.

## Ошибки Lua, которые убивают аддон

**Ошибка в `OnEvent`** — в чате одна строка (если `scriptErrors 1`), дальше аддон молчит:
обработчик падает, состояние ломается. → `pcall` вокруг необязательной логики + лог в
свой Trace; на mock-стенде доставлять каждое событие и смотреть, что ничего не падает.

**`bad argument #1 to 'SetTextColor'`** — цвет передан таблицей. → только числа:
`SetTextColor(c.r, c.g, c.b)`; в mock-клиенте ставить строгую проверку типов, чтобы
такое ловилось тестом, а не в игре.

**`attempt to call a nil value (SetBackdrop)`** — фрейм создан без `BackdropTemplate`.
→ `CreateFrame("Frame", name, parent, "BackdropTemplate")`.

**`attempt to index a nil value (field 'db')`** — код обратился к `ns.db` до
`ADDON_LOADED`. → всё, что читает БД, только после загрузки; модули не выполняют работу
на этапе `local`.

**`math.atan2` nil** — в Lua 5.1 его нет. → `math.atan2 or function(y, x) return math.atan(y, x) end`.

**`GetStringHeight` вернул nil** — текст ещё не отрисован. → фолбэк-оценка по длине/ширине.

**`attempt to concatenate a nil value`** при показе тултипа — предмет не загружен.
→ свой кэш имени + `SetText` с «загрузка...», повтор по `GET_ITEM_INFO_RECEIVED`.

## Интерфейс

**Пустые «квадратики» вместо символов** — в шрифте клиента нет `·`, `−`, `✓`, `→`, `…`.
→ `•`, `-`, `>`, `...` (проверено на ruRU 12.x; на других клиентах шрифты те же).

**Дочернее окно уезжает под главное** — главное окно при клике поднимается наверх своего
слоя. → отдельные фреймы с `SetFrameStrata("FULLSCREEN_DIALOG")` и `Raise()` при показе.

**Кнопка с длинным текстом обрезается** — ширина кнопки меньше текста, автоподгонки нет.
→ задавать ширину по длине (`ширина ≈ длина * 7 px` для 12-пт шрифта) или переносить.

**Длинное имя предмета наезжает на соседнюю строку** — включён перенос.
→ `SetWordWrap(false)` + обрезка с «...»; высоту строки считать по `GetStringHeight`.

**После смены языка половина окна на старом языке** — тексты записаны в FontString.
→ пересобирать окно/кнопку миникарты/страницу настроек по `Locale.OnChange`.

**Esc не закрывает окно** — фрейм не в `UISpecialFrames`. → `tinsert` один раз (без дублей).

**Окно уехало за экран после смены разрешения** — сохранённая позиция без проверки.
→ `SetClampedToScreen(true)` и нормализация позиции при показе.

**Список тормозит** — `C_Item.GetItemInfo` и `PlayerHasTransmog` на каждую перерисовку.
→ кэш метаданных, обновление одной строки, пул строк, только видимые.

**`OnUpdate` работает на скрытом окне** — обработчик живёт, пока фрейм существует.
→ снимать `SetScript("OnUpdate", nil)` при `Hide`, или запускать тикер только при показе.

**Штатный скролл «прыгает страницей»** — так устроен `UIPanelScrollFrameTemplate`.
→ свой скролл на колесе/ползунке (см. `03-ui.md`), либо честно оставить штатный.

**Настройки аддона не появляются в «Аддоны»** — не зарегистрирована категория.
→ `Settings.RegisterCanvasLayoutCategory` + `Settings.RegisterAddOnCategory` (через `pcall`,
после `PLAYER_LOGIN`); на старом клиенте — `InterfaceOptions_AddCategory`.

**Правая кнопка на кнопке миникарты ничего не делает** — нет меню.
→ `MenuUtil.CreateContextMenu` с фолбэком на `EasyMenu`.

## Данные и сохранение

**Настройки не сохраняются** — забыт `## SavedVariables` в TOC или БД не создана.
→ объявить в TOC, инициализировать в `ADDON_LOADED`, писать через `ns.db`.

**После входа часть БД `nil`** — в SavedVariables попали функции/фреймы/циклы: сериализатор
их молча выбросил. → хранить только числа/строки/булевы/таблицы.

**Новая настройка есть у новых, нет у старых** — нет миграции.
→ `ApplyDefaults` при загрузке (см. `01-anatomy.md`), для переименований — `db.version`.

**Попытки удваиваются за одно убийство** — одно событие приходит двумя путями
(`BOSS_KILL` + `ENCOUNTER_END`). → помнить ключ + время последнего и игнорировать повтор
в пределах 10 секунд.

**Рыбалка не считается** — клиент отдаёт заброс `UNIT_SPELLCAST_START` (а не только
`CHANNEL_START`/`SUCCEEDED`). → слушать оба, дубли гасить окном 1 секунда.

**Окно добычи не пришло** — в 12.x при автоподборе приходит `LOOT_READY`, а `LOOT_OPENED`
может не быть. → слушать оба.

**Формат `CHAT_MSG_LOOT` без ссылки** — предмет ищется по названию в `[...]`.
→ второй путь по имени + кэш «название → itemID» из своей базы.

**Торговец/цены/ассортимент пусты** — клиент отдаёт их только при открытом окне торговца.
→ читать на `MERCHANT_SHOW`, кэшировать; до этого показывать «нет данных».

**Координат мобов нет** — в базе игры их нет. → запоминать позицию при встрече
(`C_Map.GetBestMapForUnit` + `GetPlayerMapPosition`), кнопка «точка» активна только после.

**Шанс «примерно 1%»** — не выдумывать. Если источник не дал шанс — «—»/«?».

## Taint и защищённые вызовы

**Аддон «исчез» после открытия рейда/банка** — попытка изменить защищённый фрейм или
вызвать защищённую функцию из taint. → `hooksecurefunc` вместо замены; проверять
`InCombatLockdown()` и откладывать до `PLAYER_REGEN_ENABLED`; не трогать боевые фреймы
Blizzard и `SecureActionButtonTemplate`.

**Тест на mock прошёл, в игре — запрет** — заглушка не моделирует защищённость.
→ любые сомнительные вызовы делать по «белому списку» и проверять версию клиента,
а не пробовать-и-ловить.

**`ADDON_ACTION_BLOCKED` на действии игрока** — аддон вызвал защищённое действие из
своего обработчика вместо действия игрока. → не автоматизировать клики/касты.

## Внешние данные

**Wowhead отдаёт 202/403/капчу** — WAF по IP/сессии. → пауза 10–30 минут, смена темпа,
прохождение проверки человеком; для массовых страниц — сбор из уже открытого браузера
(`06-external-data.md`).

**CSV с wago.tools начинается с `1f24`/`a3f`** — chunked-ответ записан как есть.
→ скачивание с разбором chunked (`--via ssh`) и `--force`.

**`mountID`/`speciesID` = 0 у всех** — связь ищется не через `ItemXItemEffect` +
`ItemEffect.SpellID` (у `ItemEffect.ID` — ID эффекта, не предмета).

**База маунтов/петов вдвое меньше** — нет `ItemSparse_ruRU` (имена из урезанного
`ItemSearchName_ruRU`).

**Правил `Data*.lua` руками — пропало после пересборки** — файлы генерируются.
→ правки только в генератор.

**Новый патч — старые ID/спеллы** — номера заклинаний и itemID меняются, сборки DB2 новые.
→ обновить `BUILD_ID`, пересобрать базы, прогнать тесты на эталонных записях.

## Релиз

**CurseForge «invalid archive»** — в zip вложенная папка `MyAddon/MyAddon/` или файлы в
корне. → ровно одна корневая папка, проверить `namelist()` в сборщике.

**В архиве `tools/`, `node_modules/`, `.git`** — сборщик копирует всё подряд.
→ фильтр по расширениям и исключениям.

**«Аддон устарел» после обновления** — `## Interface` не обновлён под клиент.

**Версия в окне не совпадает с TOC** — `ns.version` забыли поднять. → держать в одном
месте или сверять тестом.

**Перевод «сломался» после правки русского текста** — изменился ключ словаря.
→ править строку и запускать `rekey.py`, а не только `L("...")`.

**Азиатский язык включён на русском клиенте — квадраты** — нет проверки шрифта.
→ `Locale.Supported` с `script`.

## Тесты

**`attempt to index a nil value (global 'table')` на первом файле аддона** — файлы грузятся
с `env = MOCK`, и подмена окружения убирает стандартные библиотеки. → прокинуть
`table/string/math/pairs/...` в MOCK (или скопировать `_G` в MOCK в конце `mock.lua`).

**«Окно открылось» падает** — в заглушке новый фрейм создан видимым, а `Toggle` сразу его
прячет. В клиенте новый фрейм скрыт. → `__shown = false` по умолчанию.

**Проверка «боевой лог закрыт» врёт** — в заглушке `GetBuildInfo()` возвращает toc третьим,
а клиент — четвёртым (`version, build, date, tocversion`).

**`L()` не виден в тесте** — он определён в окружении аддона (MOCK). → `local L = MOCK.L`
после загрузки.

**Тест зелёный, в игре ошибка** — заглушка не знает реальных сигнатур и taint. → сверять
вызовы с `wow-ui-source`, а не только с mock.

## Окружение разработки

**Внешние запросы не проходят** — нет прокси/сети. → сначала поднять локальный прокси
(`127.0.0.1:10808`) или SSH-форвард, только потом говорить «сайт недоступен».

**`curl`/`requests` получают HTML-заглушку вместо страницы** — WAF/капча, не «сайт упал».
→ см. `06-external-data.md`, не обходить автоматически.

**Скрипт сборки пишет файл, а игра не видит изменений** — не выложено в
`Interface/AddOns` или нужен `/reload`. → выкладка + `/reload` в чеклисте.
