# starter — рабочий скелет аддона

Этот каталог — минимальный аддон, который **реально грузится в WoW** (12.1.5+):
TOC, локализация, база с миграцией настроек, слэш-команды, окно с двумя вкладками,
список строк, кнопка у миникарты, страница в «Настройках → Аддоны», привязка клавиши.

## Как использовать

1. Скопировать каталог в `Interface/AddOns/MyAddon/` и переименовать:
   - `MyAddon.toc` → `<Имя>.toc` (имя = имя папки!);
   - `MyAddonDB` / `MyAddonCharDB` → свои имена (TOC + `Core.lua`);
   - строки `My Addon` / `MyAddon` / `MA` в коде — на своё название.
2. Открыть `Core.lua` и `UI.lua`, править по месту.
3. Прогнать тесты из `../uitest`: `node check.js ../starter && node run.js ../starter`.
4. `/reload` в игре, `/ma` — окно.

## Что где

| Файл | Что внутри |
|---|---|
| `MyAddon.toc` | метаданные, SavedVariables, порядок файлов |
| `Core.lua` | база, ApplyDefaults, слэш-команды, события, обёртки (`ns.Open`, `ns.ResolveItemID`) |
| `Locale.lua` | `L()`, языки, `Locale.Supported` (шрифты), переключение |
| `Locale_en.lua` | английский словарь (ключ — русская строка) |
| `UI.lua` | окно, вкладки, пул строк, миникарта, настройки, пересборка при смене языка |
| `Bindings.xml` | привязка клавиши (функция `MyAddon_Toggle` + `BINDING_HEADER_MYADDON`) |

## Чего здесь намеренно нет

Генераторов `Data*.lua`, сканеров коллекций, внешних сборщиков, темы/палитр — это
надстройки над каркасом. Подходы к ним — в `references/04-events-data.md`,
`references/06-external-data.md`, `references/03-ui.md`.
