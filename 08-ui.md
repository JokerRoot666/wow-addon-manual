# 8. Работа с UI: окна, кнопки, текстуры, шрифты, прокрутка

## 8.1 Зачем это нужно

Скелет (разделы 3–7) умеет считать, но не умеет показывать. Этот раздел — про то, как из
фреймов собрать окно, которое не стыдно показать: панели, вкладки, строки списка, своя
прокрутка, подсказки, страница в настройках и кнопка у миникарты.

Все приёмы взяты из DropLedger — это единственный источник готовых рецептов, вики таких
сборок не описывает (см. план, раздел 8).

## 8.2 Базовые строительные блоки

| Что нужно | Чем делается | Источник |
|---|---|---|
| прямоугольник без содержимого | `CreateFrame("Frame", …)` | [API:CreateFrame](https://warcraft.wiki.gg/wiki/API:CreateFrame) |
| фон и рамка | `CreateFrame(…, "BackdropTemplate")` + `SetBackdrop` | [BackdropTemplate](https://warcraft.wiki.gg/wiki/BackdropTemplate) |
| заливка цветом | `texture:SetColorTexture(r, g, b, a)` | [API:TextureBase_SetTexture](https://warcraft.wiki.gg/wiki/API:TextureBase_SetTexture) |
| картинка | `texture:SetTexture("путь\\файл")` | там же |
| текст | `frame:CreateFontString(nil, "OVERLAY", "GameFontNormal")` | [API:Frame_CreateFontString](https://warcraft.wiki.gg/wiki/API:Frame_CreateFontString) |
| кликабельная область | `CreateFrame("Button", …)` | [API:CreateFrame](https://warcraft.wiki.gg/wiki/API:CreateFrame) |
| ввод текста | `CreateFrame("EditBox", …)` | там же |
| прокрутка | `CreateFrame("ScrollFrame", …)` | там же |

| страница в настройках | `Settings.RegisterCanvasLayoutCategory` | [Settings API](https://warcraft.wiki.gg/wiki/Settings_API) |

## 8.3 Шрифтстринг: одна функция на весь аддон

Проблема: у `CreateFontString` размер и шрифт по умолчанию не всегда те, что нужны, а
прописывать `"Fonts\\FRIZQT__.TTF"` руками — плохо (в другой локали шрифт другой). Решение
DropLedger (`UI.lua:130-140`) — взять текущий шрифт фрейма и заменить только размер:

```lua
local function MakeFS(parent, size, color, point, relPoint, x, y)
    local fs = parent:CreateFontString(nil, "OVERLAY", "GameFontHighlightSmall")
    local path, _, flags = fs:GetFont()
    if path then fs:SetFont(path, size or 11, flags) end
    fs:SetPoint(point or "TOPLEFT", parent, relPoint or point or "TOPLEFT", x or 0, y or 0)
    fs:SetJustifyH("LEFT")
    fs:SetTextColor((color or C.text)[1], (color or C.text)[2], (color or C.text)[3])
    return fs
end
```

| Строка | Что делает | Источник |
|---|---|---|
| `CreateFontString(nil, "OVERLAY", "GameFontHighlightSmall")` | текст поверх текстур, готовый стиль | [API:Frame_CreateFontString](https://warcraft.wiki.gg/wiki/API:Frame_CreateFontString) |
| `GetFont()` | вернуть `path, height, flags` текущего шрифта | [API:FontInstance_SetFont](https://warcraft.wiki.gg/wiki/API:FontInstance_SetFont) |
| `SetFont(path, size, flags)` | подменить размер, сохранив начертание | там же, «The flags parameter is no longer optional» |
| `SetTextColor` | цвет в 0…1 | — |
| `SetPoint("TOPLEFT", …)` | позиция относительно родителя | [API:ScriptRegionResizing_SetPoint](https://warcraft.wiki.gg/wiki/API:ScriptRegionResizing_SetPoint) |

Помните про лимит: «FontString has a limit of 30,000 characters» и «The font must be set before
showing text» ([API:FontString_SetText](https://warcraft.wiki.gg/wiki/API:FontString_SetText)).

## 8.4 Кнопка

Кнопка отличается от фрейма тремя вещами: она получает клики, имеет состояния и умеет
показывать подпись. Минимальная рабочая кнопка без шаблонов (`UI.lua:190-235`, сокращённо):

```lua
local b = CreateFrame("Button", nil, parent, "BackdropTemplate")
b:SetSize(width, height)
b:SetBackdrop({ bgFile = WHITE, edgeFile = WHITE, edgeSize = 1 })
b:SetBackdropColor(BTN_BG[1], BTN_BG[2], BTN_BG[3], 1)
b:SetBackdropBorderColor(BTN_BORDER[1], BTN_BORDER[2], BTN_BORDER[3], 1)

b.label = MakeFS(b, 11, C.text, "CENTER", "CENTER", 0, 0)
b.label:SetJustifyH("CENTER")
b.label:SetText(text or "")

b:SetScript("OnEnter", function(self)
    self:SetBackdropColor(C.hover[1], C.hover[2], C.hover[3], 1)
    self:SetBackdropBorderColor(C.accent[1], C.accent[2], C.accent[3], 0.9)
    if self.tip then
        GameTooltip:SetOwner(self, "ANCHOR_RIGHT")
        GameTooltip:AddLine(self.tip)
        GameTooltip:Show()
    end
end)

b:SetScript("OnLeave", function(self)
    self:SetBackdropColor(BTN_BG[1], BTN_BG[2], BTN_BG[3], 1)
    self:SetBackdropBorderColor(BTN_BORDER[1], BTN_BORDER[2], BTN_BORDER[3], 1)
    GameTooltip:Hide()
end)

b:SetScript("OnClick", onClick)
```

Что даёт `Button` помимо `Frame` (из [API:CreateFrame](https://warcraft.wiki.gg/wiki/API:CreateFrame)
и [UIOBJECT_Button](https://warcraft.wiki.gg/wiki/UIOBJECT_Button)):

* скрипты `OnClick`, `OnMouseDown`, `OnMouseUp`, `OnEnter`, `OnLeave`, `OnDragStart`, `OnDragStop`;
* `RegisterForClicks("AnyDown", "AnyUp")` — какие события мыши считать кликом;
* `SetHighlightTexture(...)` — подсветка при наведении;
* `SetText(...)`, если наследуется от шаблона с подписью.

Одна тонкость: `EnableMouse` не нужен, если задан `OnEnter`/`OnMouseDown` — «Setting the
OnEnter/Leave, OnMouseDown/Up script automatically implies EnableMouse(true)»
([API:ScriptRegion_EnableMouse](https://warcraft.wiki.gg/wiki/API:ScriptRegion_EnableMouse)).

## 8.5 Вкладки

DropLedger рисует вкладки сам — одна функция `NewTab`, шесть внешних видов (`UI.lua:265-350`).
Ключевая идея: **вкладка — это кнопка с полем `tabKey`**, а переключение — показ/скрытие
готовых панелей, а не пересоздание содержимого.

```lua
local function NewTab(parent, key, text, width, height, shape, fontSize, onClick)
    local b = CreateFrame("Button", nil, parent, "BackdropTemplate")
    b:SetSize(width, height)
    b.tabKey  = key
    b.shape   = shape or "button"
    b.enabled = true
    b.active  = false

    if b.shape ~= "icon" then
        b.label = MakeFS(b, fontSize or 10, C.text, "CENTER", "CENTER", 0, 0)
        b.label:SetJustifyH("CENTER")
        b.label:SetText(text or "")
        b.label:SetWidth(width - 6)
    end
    ...
```

Почему не `TinyTabs`-подобный шаблон Blizzard: у каждой панели своя раскладка (8 вариантов
оформления), и проще нарисовать кнопку, чем подгонять чужой шаблон. Для стажёра правило:
**если хочется «как в Blizzard» — берите шаблон; если своя сетка — рисуйте кнопку.**

## 8.6 Список строк: пул, а не создание

Список из 500 предметов нельзя делать 500 фреймами: «Frames cannot be deleted or garbage
collected, so it may be preferable to reuse them»
([API:CreateFrame](https://warcraft.wiki.gg/wiki/API:CreateFrame)).

Правильный шаблон — пул строк: создаём N строк «на высоту окна», дальше только подменяем
текст и данные.

```lua
local rows = {}          -- пул
local ROW_H = 20

local function GetRow(i, parent)
    local row = rows[i]
    if row then return row end

    row = CreateFrame("Button", nil, parent)
    row:SetHeight(ROW_H)
    row:SetPoint("TOPLEFT", parent, "TOPLEFT", 0, -(i - 1) * ROW_H)
    row:SetPoint("TOPRIGHT", parent, "TOPRIGHT", 0, -(i - 1) * ROW_H)

    row.icon  = row:CreateTexture(nil, "ARTWORK")
    row.icon:SetSize(16, 16)
    row.icon:SetPoint("LEFT", row, "LEFT", 2, 0)

    row.name  = MakeFS(row, 11, C.text, "LEFT", "LEFT", 24, 0)
    row.right = MakeFS(row, 11, C.dim, "RIGHT", "RIGHT", -4, 0)
    row.right:SetJustifyH("RIGHT")

    rows[i] = row
    return row
end

function RefreshList(items)
    for i = 1, #items do
        local row = GetRow(i, listPanel)
        row.icon:SetTexture(items[i].icon)
        row.name:SetText(items[i].name)
        row.right:SetText(items[i].chance)
        row.itemID = items[i].id
        row:Show()
    end
    for i = #items + 1, #rows do rows[i]:Hide() end
end
```

`row.itemID` + замыкание в `OnClick` — тот самый приём из 2.5: обработчик помнит свою строку.

## 8.7 Своя прокрутка

Штатный шаблон прокрутки Blizzard в DropLedger не используется: в комментарии к коду
записано, что `UIPanelScrollFrameTemplate` листает страницей за клик и список «прыгает»,
поэтому прокрутка сделана своя (`UI.lua:473-560`). Это решение нашего аддона, а не
требование клиента. Минимум, без которого прокрутка не работает:

```lua
local scroll = CreateFrame("ScrollFrame", nil, panel)
scroll:SetPoint("TOPLEFT", panel, "TOPLEFT", x, y)
scroll:SetSize(w, h)
scroll:EnableMouseWheel(true)

local content = CreateFrame("Frame", nil, scroll)
content:SetSize(w - 12, 1)
scroll:SetScrollChild(content)
```

| Метод | Зачем | Источник |
|---|---|---|
| `EnableMouseWheel(true)` | получать `OnMouseWheel` | [UIOBJECT_Frame](https://warcraft.wiki.gg/wiki/UIOBJECT_Frame) |
| `SetScrollChild(content)` | что именно прокручивать | [UIOBJECT_ScrollFrame](https://warcraft.wiki.gg/wiki/UIOBJECT_ScrollFrame) |
| `GetVerticalScrollRange()` | максимальное смещение | там же |
| `SetVerticalScroll(v)` / `GetVerticalScroll()` | позиция | там же |
| скрипты `OnVerticalScroll`, `OnScrollRangeChanged` | реакция на прокрутку и на изменение высоты | там же |

Ползунок рисуется вручную и пересчитывается по формуле из `UI.lua:534-548`:

```lua
UpdateThumb = function()
    local maxv   = MaxScroll()
    local trackH = track:GetHeight() or 0
    local viewH  = h
    local thumbH = trackH
    if maxv > 0 then
        thumbH = math.max(24, trackH * (viewH / (viewH + maxv)))
    end
    thumb:SetHeight(thumbH)
    local frac = 0
    if maxv > 0 then
        frac = (scroll:GetVerticalScroll() or 0) / maxv
        if frac < 0 then frac = 0 end
        if frac > 1 then frac = 1 end
    end
    thumb:ClearAllPoints()
    thumb:SetPoint("TOP", track, "TOP", 0, -frac * math.max(0, trackH - thumbH))
    track:SetShown(maxv > 0)
end
```

Три правила, которые видно в этом коде:

1. **`thumb:ClearAllPoints()` перед повторным `SetPoint`** — иначе якорей становится два и
   ползунок «застревает» (см. 4.3 про семейства якорей).
2. **Минимум 24 пикселя** — иначе на огромном списке ползунок превращается в точку.
3. **`track:SetShown(maxv > 0)`** — если прокручивать нечего, полоса не показывается.

Колесо обрабатывается отдельно и с анимацией: `cur` догоняет `target` в `OnUpdate`, шаг
`SCROLL_WHEEL = 46` пикселей на деление. Это тот случай, когда `OnUpdate` оправдан.

## 8.8 Подсказки

```lua
GameTooltip:SetOwner(self, "ANCHOR_RIGHT")
GameTooltip:AddLine("строка текста")
GameTooltip:AddDoubleLine("слева", "справа", 1, 1, 1, 0.8, 0.8, 0.8)
GameTooltip:Show()
-- при уходе курсора
GameTooltip:Hide()
```

| Метод | Сигнатура и замечание | Ссылка |
|---|---|---|
| `SetOwner` | `GameTooltip:SetOwner(owner, "anchor"[, ofsX, ofsY])`; «positive values move tooltip to the right» / «up» | [API:GameTooltip_SetOwner](https://warcraft.wiki.gg/wiki/API:GameTooltip_SetOwner) |
| `AddLine` | `AddLine(tooltipText [, r, g, b, wrapText])`; без цветов «the line appears in the game's normal font color (gold)» | [API:GameTooltip_AddLine](https://warcraft.wiki.gg/wiki/API:GameTooltip_AddLine) |
| `AddDoubleLine` | `AddDoubleLine(textL [, textR, rL, gL, bL, rR, gR, bR])` | [API:GameTooltip_AddDoubleLine](https://warcraft.wiki.gg/wiki/API:GameTooltip_AddDoubleLine) |
| `SetText` | `SetText(text [, r, g, b, alpha, textWrap])` | [API:GameTooltip_SetText](https://warcraft.wiki.gg/wiki/API:GameTooltip_SetText) |

Анкоры: `ANCHOR_RIGHT`, `ANCHOR_LEFT`, `ANCHOR_TOP`, `ANCHOR_BOTTOM`, `ANCHOR_CURSOR`,
`ANCHOR_PRESERVE`, `ANCHOR_NONE` и диагональные
([API types/TooltipAnchor](https://warcraft.wiki.gg/wiki/API_types/TooltipAnchor)).
`ANCHOR_PRESERVE` — «Stays at the position you initially set it to», `ANCHOR_NONE` — «No call
to :SetPoint() will be made. You must call it manually».

Важно: «calling this function on an already-visible tooltip will cause the new line to appear
outside of the tooltip's backdrop» — то есть перед новым набором строк нужен `SetOwner`
или `ClearLines`.

## 8.9 Страница в «Настройках игры»

С 10.0.0 интерфейс настроек переехал на `Settings`:

> «The Settings API was redone in patch 10.0.0 with additional breaking changes in patch 11.0.2.»
> — [Settings API](https://warcraft.wiki.gg/wiki/Settings_API)

Минимальный вариант (панель-канвас) — дословно из
[Creating a settings menu](https://warcraft.wiki.gg/wiki/Creating_a_settings_menu):

```lua
local frame = CreateFrame("Frame")
local background = frame:CreateTexture()
background:SetAllPoints(frame)
background:SetColorTexture(1, 0, 1, 0.5)

local category = Settings.RegisterCanvasLayoutCategory(frame, "My AddOn")
Settings.RegisterAddOnCategory(category)
```

В DropLedger это обёрнуто в проверки и `pcall` (`UI.lua:7019-7060`), потому что старый клиент
может не иметь этих функций:

```lua
function UI.RegisterOptions()
    if UI.optCategory then return end
    if not (Settings and Settings.RegisterCanvasLayoutCategory and Settings.RegisterAddOnCategory) then return end
    if not ns.db then return end

    local panel = CreateFrame("Frame")
    panel:SetSize(560, 420)
    ...
    local ok, category = pcall(Settings.RegisterCanvasLayoutCategory, panel, "Drop Ledger")
    if ok and category then
        pcall(Settings.RegisterAddOnCategory, category)
        UI.optCategory = category
    end
end
```

Ключевые функции из [Settings API](https://warcraft.wiki.gg/wiki/Settings_API):

| Функция | Назначение |
|---|---|
| `Settings.RegisterCanvasLayoutCategory(frame, name)` | страница, содержимое которой — ваш фрейм |
| `Settings.RegisterAddOnCategory(category)` | добавить страницу в список аддонов |
| `Settings.RegisterCanvasLayoutSubcategory(parentCategory, frame, name)` | подстраница |
| `Settings.OpenToCategory(category, [scrollToElementName])` | открыть на нужной странице |
| `Settings.RegisterAddOnSetting(categoryTbl, variable, variableKey, variableTbl, variableType, name, defaultValue)` | отдельный контрол |

Старый путь удалён: «This FrameXML function has been replaced by Settings.OpenToCategory… It was
deprecated in patch 10.0.0 in Blizzard_Deprecated.lua» —
[InterfaceOptionsFrame_OpenToCategory](https://warcraft.wiki.gg/wiki/InterfaceOptionsFrame_OpenToCategory).

## 8.10 Кнопка у миникарты

Готового рецепта в вики нет — берём `UI.lua:6896-6960`. Идея: кнопка-ребёнок `Minimap`,
позиция считается по углу на окружности.

```lua
local b = CreateFrame("Button", "DropLedgerMinimapButton", Minimap)
b:SetSize(32, 32)
b:SetFrameStrata("MEDIUM")
b:SetFrameLevel(Minimap:GetFrameLevel() + 10)
b:RegisterForDrag("LeftButton")

b.border = b:CreateTexture(nil, "BACKGROUND")
b.border:SetSize(54, 54)
b.border:SetPoint("CENTER", b, "CENTER", 0, 0)
b.border:SetTexture("Interface\\Minimap\\MiniMap-TrackingBorder")

b.icon = b:CreateTexture(nil, "ARTWORK")
b.icon:SetSize(20, 20)
b.icon:SetPoint("CENTER", b, "CENTER", 0, 1)
b.icon:SetTexture("Interface\\Icons\\INV_Misc_Coin_01")
b.icon:SetTexCoord(0.08, 0.92, 0.08, 0.92)
```

и перетаскивание по кругу:

```lua
local function Place(a)
    local w = Minimap.GetWidth and Minimap:GetWidth() or 140
    if not w or w < 40 then w = 140 end
    local radius = w / 2 + 5
    b:ClearAllPoints()
    b:SetPoint("CENTER", Minimap, "CENTER",
        radius * math.cos(math.rad(a)), radius * math.sin(math.rad(a)))
end

b:SetScript("OnDragStart", function(self)
    self:SetScript("OnUpdate", function()
        local mx, my = Minimap:GetCenter()
        if not mx then return end
        local scale = Minimap:GetEffectiveScale() or 1
        local cx, cy = GetCursorPosition()
        cx, cy = cx / scale, cy / scale
        local a = math.deg(atan2(cy - my, cx - mx))
        angle = a
        ns.db.ui.minimapAngle = a
        Place(a)
    end)
end)
b:SetScript("OnDragStop", function(self) self:SetScript("OnUpdate", nil) end)
```

Три вещи, которые легко забыть: `SetFrameLevel(Minimap:GetFrameLevel() + 10)` (иначе кнопка
под картой), `GetEffectiveScale()` при пересчёте координат и сохранение угла в базу, чтобы
кнопка не прыгала после `/reload`.

## 8.11 Модель: примерочная

Тип `DressUpModel` есть в списке `CreateFrame`
([API:CreateFrame](https://warcraft.wiki.gg/wiki/API:CreateFrame)), конкретные методы в вики не
разобраны — берём `UI.lua:4018-4040`:

```lua
local model = CreateFrame("DressUpModel", nil, f.stage)
model:SetAllPoints(f.stage)
model:SetUnit("player")
-- показываем именно надетую вещь, а не её трансмог-подмену
pcall(model.SetUseTransmogChoices, model, false)
pcall(model.SetUseTransmogSkin, model, false)
pcall(model.SetAutoDress, model, false)
pcall(model.SetCamDistanceScale, model, tryZoom)
```

`pcall` здесь не суеверие: набор методов модели менялся между версиями клиента, и вызов
несуществующего метода не должен ронять весь аддон.

## 8.12 Порядок сборки окна

Порядок, который работает (и который видно в `UI.OnLoad`):

1. Создать корневой фрейм (`CreateFrame("Frame", "MyAddonFrame", UIParent, "BackdropTemplate")`).
2. Задать размер и позицию (`SetSize`, `SetPoint`), при сохранённой позиции — из базы.
3. Создать панели-контейнеры (шапка, список, футер).
4. Создать вкладки и связать их с панелями.
5. Создать строки списка (пул).
6. Зарегистрировать страницу настроек и кнопку у миникарты.
7. `Hide()` — окно не должно появляться само.

И только после этого — `Refresh()`, который наполняет строки данными. Если сделать наоборот,
получите строки, которые создаются заново на каждое обновление.

## 8.13 Частые ошибки новичка

| Симптом | Причина | Источник |
|---|---|---|
| Окно белое/прозрачное без рамки | нет `BackdropTemplate` | [API:Frame_SetBackdrop](https://warcraft.wiki.gg/wiki/API:Frame_SetBackdrop) |
| Текст «пропал» | шрифтстринг в слое ниже фона | [Layer](https://warcraft.wiki.gg/wiki/Layer) |
| Кнопка не нажимается | перекрыта другим фреймом (страта/уровень) | [Frame Strata](https://warcraft.wiki.gg/wiki/Frame_Strata) |
| Список тормозит | строки создаются заново | [API:CreateFrame](https://warcraft.wiki.gg/wiki/API:CreateFrame) |
| Ползунок «застревает» | два якоря без `ClearAllPoints` | 8.7 |
| Прокрутка не работает колесом | нет `EnableMouseWheel(true)` | [UIOBJECT_Frame](https://warcraft.wiki.gg/wiki/UIOBJECT_Frame) |
| Тултип «уезжает» | `AddLine` на уже показанном тултипе | [API:GameTooltip_AddLine](https://warcraft.wiki.gg/wiki/API:GameTooltip_AddLine) |
| Страница настроек пустая | забыли `Settings.RegisterAddOnCategory` | [Creating a settings menu](https://warcraft.wiki.gg/wiki/Creating_a_settings_menu) |
| Кнопка у миникарты под картой | не выставлен `SetFrameLevel` | 8.10 |
